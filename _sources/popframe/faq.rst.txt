FAQ / Часто задаваемые вопросы
=============================

**EN:**
Frequently asked questions and answers about PopFrame.

**RU:**
Часто задаваемые вопросы и ответы о PopFrame.

.. topic:: What is PopFrame? / Что такое PopFrame?

    **EN:** PopFrame is an open-source library for modeling regional settlement systems and territory assessment.
    
    **RU:** PopFrame — это open-source библиотека для моделирования каркаса расселения и оценки территорий.

.. topic:: How do I install PopFrame? / Как установить PopFrame?

    **EN:** Use pip: pip install popframe
    
    **RU:** Используйте pip: pip install popframe

.. topic:: Where can I find examples? / Где найти примеры?

    **EN:** See the examples/ directory in the repository or the documentation section "Examples".
    
    **RU:** Смотрите папку examples/ в репозитории или раздел "Примеры" в документации.
