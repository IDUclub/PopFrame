A class representing a geographical region that includes districts, settlements, towns, and optionally territories. Provides methods for validating and visualizing spatial data, as well as for calculating accessibility between towns.

prepare_for_analysis(*, repair_geometry: bool = False) → Region[source]

Validate a loaded model and return an independent copy in local UTM.

Checks geometries, population, town IDs and the travel-time matrix; aligns matrix rows and columns with towns and recalculates size levels. The source model is not modified. Matrix values must already represent minutes: units cannot be inferred or converted by this method. Positive infinity is allowed for unreachable pairs; the diagonal must be zero. At least two towns are required for the analysis workflow.

Parameters

repair_geometrybool, default False

Repair invalid boundary polygons with make_valid. Retain polygonal parts of resulting geometry collections, discarding line/point remnants. Empty or non-polygonal results still raise ValueError.

Raises
