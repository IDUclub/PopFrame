class popframe.preprocessing.data_loader.RegionDataLoader(place_query: str | dict, *, cache_dir: str | Path = 'cache/osm', overpass_endpoint: str = 'https://maps.mail.ru/osm/tools/overpass/api', attempts: int = 4, timeout: int = 300, routing_buffer_m: float = 20000)[source]

Bases: object

Download a region’s boundary, named place nodes and directed drive graph.

Completed downloads and place tiles are reused from cache_dir. Cache parameters are checked to prevent mixing regions. OSMnx’s global settings are restored after each network operation, including failed operations. Use sequentially: OSMnx itself configures requests through global settings.

popframe.preprocessing.data_loader.build_region(boundary: GeoDataFrame, towns: GeoDataFrame, graph: MultiDiGraph, *, max_snap_distance_m: float = 2000) → Region[source]

Validate population, snap towns and build a Region with directed minutes.

Inputs are not modified. Missing population and remote road attachments raise ValueError with town IDs. Unreachable pairs remain positive infinity. Travel times exclude congestion and the approach from a town to its road node; different towns attached to the same node may have zero travel time.
